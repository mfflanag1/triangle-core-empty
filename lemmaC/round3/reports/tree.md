## 1. Definitions

Limit object T: rooted hypertree, root agent o. At every agent the costs of its teams
(other than the team it was reached through) form a Poisson process of intensity
Lambda(dxi) = xi^2/2 dxi, independent over agents. Every team has 3 agents. The incidence
graph is a tree. Unimodular by Mecke.

- IFPM (invariant fractional perfect matching): unimodular (T,o,xi,x) with the
  (T,o,xi)-marginal above, x_e in [0,1], sum over e containing v of x_e = 1 at every agent.
  Extra randomness allowed; "factor" if x is a function of (T,xi).
- IRIPM (invariant random integral perfect matching): the same with x in {0,1}.
- Cost c(x) = E sum over e containing o of xi_e x_e (per team; per agent it is c/3).
  a_tree = inf of c over IFPMs.
- Typical IRIPM: a local weak limit, with probability bounded away from 0, of
  (market, N_q) for perfect assignments N_q of the actual market.
  FIID-limits ⊂ typical ⊂ unimodular, and the inclusions can be strict.

## 2. Decomposition: yes, explicitly

**Lemma B0 (claimed complete).** A finite hypertree has at most one perfect matching. Two
perfect matchings of any hypertree differ on a union of infinite leafless alternating
sub-hypertrees. Proof: in the symmetric difference agents have degree 2 and teams degree 3;
a finite tree has a leaf.

**Theorem B (claimed complete).** For any hypertree H (countable degrees allowed) and
fractional perfect matching x there is a measure mu_{H,x} on integral perfect matchings
with (i) mu(e in m) = x_e, (ii) mu root-independent and isomorphism-equivariant. Hence for
an IFPM, (T,o,xi,x,m) with m ~ mu_{T,x} is unimodular, m is an IRIPM,
E[m_e | T,xi,x] = x_e, and c(m) = c(x).

Construction: the root picks team e with probability x_e. Going outward: an agent reached
through a team in m picks nothing; an agent w reached through a team f not in m picks one
of its other teams g with probability x_g/(1 - x_f). A team is in m iff it is picked.

Proof.
1. Valid: each agent is in exactly one picked team; a picked team's other two agents are
   reached through it and pick nothing (uses the tree structure).
2. Marginals by induction: P(g in m) = (1 - x_f)·x_g/(1 - x_f) = x_g.
3. Root independence: for the three agents o, o', o'' of a team f, the joint law of their
   chosen teams is (f,f,f) with probability x_f and (e,g,h), all different from f, with
   probability x_e x_g x_h/(1 - x_f)^2, which is symmetric. Given these, the subtrees away
   from f are generated by the same outward kernels whichever agent is the root.
4. Unimodularity: F(H,x,o,v) = integral of f(H,x,m,o,v) dmu is a function of the doubly
   rooted (H,x), so mass transport passes through.
5. Cost by monotone convergence. QED.

No compactness is needed; mu is the Bethe (tree-Markov) measure.

**Corollary B1 (claimed complete).** inf over IRIPMs = inf over IFPMs = a_tree.

**Corollary B2 (complete given that the two cavity fixed points exist as recursive tree
processes, which is numerical).** M_RS (e in M iff xi_e < X_{a->e} + X_{b->e} + X_{c->e},
symmetric in a, b, c, so a consistent IRIPM) costs 2.2495. The fractional fixed point is an
IFPM of cost 2.197. So there is an IRIPM of cost 2.197. M_RS is not the cheapest invariant
integral matching, and "a_IP >= a_RS" has no tree-level justification.

Which alternative: the conjecture is not a statement about the tree alone. Model case: the
all-1/2 fractional independent set on the d-regular tree decomposes into the two parity
colourings, which random regular graphs cannot realise.

Warning: mu is generally not a factor of iid, and outward randomness is not entropy per
agent in a finite market (for x = 1/d on the d-regular 3-uniform hypertree the Bethe
entropy is ln d - 2(d-1) ln(d/(d-1)) per three agents, negative for d <= 6).

Statement: a_LP = a_tree < inf{c(m): m typical IRIPM} = a_IP.

## 4. Instability as a theorem

n-fold relaxation, in the notation of ../cavity/CAVITY.md: message = slopes
s_1 <= ... <= s_n; cells g^k_m = xi_k + s^{j_k}_m + s^{l_k}_m; new s^i_m = -c_(n+1-m) with
c_(1) <= ... <= c_(n) the n smallest cells. Kink kappa = s_n - s_1. k* = argmin_k g^k_1,
Delta_i = min over k != k* of g^k_1 - g^{k*}_1.

**Theorem K (claimed complete).**
(i) kappa_i <= kappa_{j*} + kappa_{l*}, with equality iff kappa_{j*} + kappa_{l*} <= Delta_i;
for n = 2, kappa_i = min(kappa_{j*} + kappa_{l*}, Delta_i).
(ii) Let (X_v) be an invariant recursive tree process of X_i = min_k(xi_k - X_j - X_l) with
E(X + X')_+^3 < infinity. Give every depth-g agent the message -X_v + a_m, with
a_1 <= ... <= a_n constants and A = max|a_m|. On the event E_g = {Delta_v > 2^(r+1) A for
all agents v at depth g - r, 1 <= r <= g, of the root's argmin tree}, the root message is
exactly -X_o + (-2)^g a_{sigma^g(m)}, sigma(m) = n + 1 - m; so kappa_o = 2^g kappa_0.
P(E_g) -> 1 as A -> 0.
(iii) T_1(mu * delta_c) = T_1(mu) * delta_{-2c} exactly for the integral map.

Proof. (i) c_(1) = g^{k*}_1 and k*'s n cells are candidates, so c_(n) <= g^{k*}_n.
(ii) Order statistics are 1-Lipschitz in sup norm and each cell uses two children, so every
agent at depth g - r has |s_m + X_v| <= 2^r A. On the argmin tree, if the argmin children
have the exact form -X + a' with |a'| <= 2^(r-1) A, then k*'s cells are X_v + 2a'_m and all
others are >= X_v + Delta_v - 2^r A; if Delta_v > 2^(r+1) A the n smallest are k*'s and
s^v_m = -(X_v + 2a'_{n+1-m}). Induct. Finitely many agents, Delta_v > 0 a.s. QED.

Reading: the growth factor is exactly 2 = k - 1 per generation (the cavity note's "about
2.2"), and 1 for bipartite matching. By (iii) the integral fixed point is not attracting
even among integral messages (multiplier -2; -1 bipartite). NOT proved: existence of the
fractional fixed point, or a_tree < a_RS. By B0 there is no finite improving move to

## 5. Star-conditioned first moment (new)

The plain first moment (fact 4 of the brief) is dominated by markets with atypical local
environments. Condition on the star profile: each agent's binned multiset of near-tight
team costs. Given it, the Poissonised 3-partite hypergraph is exactly a configuration
model. With n_beta = lambda_beta q teams in bin beta and m_beta = p_beta q of them used:

  E #{assignments with profile p | stars}
    = (number of choice functions per sector)^3 · prod over beta of C(n_beta, m_beta)^(-2).

The number of choice functions per sector is exp(q H), where H is the maximum entropy of a
kernel "agent picks one point of its star" with marginals p, attained by picking xi in the
star Pi with probability w(xi)/W, W = sum over Pi of w. In the continuum, with
rho(xi) = P(a root team of cost xi is used) and h the binary entropy:

  Sigma[rho] = 3H - 2 ∫ h(rho) dLambda,
  H = E ln W - ∫ ln w · rho dLambda,
  rho = E[w/(w + W)],
  e[rho] = ∫ xi rho dLambda.

**Candidate bound (S):** a_IP >= e_1* := inf{ e[rho] : Sigma[rho] >= 0 }.

Checks (complete as algebra): the d-regular single bin gives ln d - 2(d-1) ln(d/(d-1)),
whose sign reproduces the known perfect-matching threshold for random d-regular 3-uniform
hypergraphs [memory: Cooper-Frieze-Molloy-Reed]. The dilute limit gives
-2 - ∫ rho ln rho dLambda, maximised at rho = (27/e^3) exp(-3 xi/e) with value
ln(e^3 exp(1)/27), exactly the plain first-moment exponent (zero at 2.1496). Numerically
Sigma <= the annealed exponent everywhere.

Numbers (quadrature; stationarity ln w = -beta xi + (2/3) ln(rho/(1 - rho))):

| beta | e | Sigma | plain exponent |
|---|---|---|---|
| 0.50 | 2.434 | +0.208 | +0.372 |
| 0.54 | 2.338 | +0.058 | +0.252 |
| 0.5573 | 2.3025 | 0 | +0.206 |
| 0.58 | 2.260 | -0.072 | +0.151 |
| 0.62 | 2.196 | -0.187 | +0.064 |
| 0.66 | 2.143 | -0.290 | -0.009 |

So e_1* = 2.3025. Maximality: the Lagrangian Sigma - 3 beta e is below its stationary value
under all 48 perturbations and 12 alternative families tested. One apparent violation
(+77) in out_star_check.txt was a quadrature artifact from unnormalised weights;
star_check2.py reruns it normalised and gets -17.3.

Meaning if (S) holds: a_IP >= 2.3025 > 2.2495 = a_RS > 2.197 = cavity a_tree; a gap of at
least 0.105, matching the finite-q gap fits (0.097 to 0.156). Depth-2 conditioning can only
raise the bound.

Gaps:
- (S-a) Sigma is not obviously concave (3H concave, -2h convex); the bound needs the global
  sup of the Lagrangian; only tested.
- (S-b) binning and the tail above K; routine, not written.
- (S-c) pair-additive model: given star profiles the real hypergraph is not a configuration
  model; one needs P(chosen half-edges are the assignment's teams) <= exp(o(q)) ×
  configuration value. The Poissonised model (iid team costs with density xi^2/2) avoids
  this and is a clean intermediate theorem.
